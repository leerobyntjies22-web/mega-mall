MeGa MaLl starter prototype

HOW TO PREVIEW
1. Unzip this folder.
2. Open index.html in a modern browser (Chrome works).
3. The prototype includes sample products, category filtering, search, a temporary cart, a seller application preview, and a commission calculator.

IMPORTANT
This is a front-end demo only. It is not yet a live multi-vendor marketplace. It has no backend/database, real accounts, online payments, seller payouts, delivery integration, or live order management. Do not enter sensitive information. Before accepting real orders, connect a secure backend, authentication, database, payment provider, privacy/terms pages, and seller payout/commission rules.

NEXT STEP
Publish the static prototype to a free hosting service for a preview link, then build the backend and real marketplace features. The live platform may require service fees as usage grows.
